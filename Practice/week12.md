# Week 12 실습 정리

## 오늘 실행해본 코드 중 가장 흥미로웠던 것

오늘 실행해본 코드 중에서는 Perlin Noise를 이용한 지형 생성 코드가 가장 흥미로웠다.

랜덤 값을 단순히 사용하는 것이 아니라,
노이즈를 이용해서 실제 자연 지형처럼 부드럽고 연결된 형태가 만들어지는 점이 인상적이었다.

특히 seed기반 지형생성이라는 점이 좋았고,
높이나 길이에 따른 경로를 꾸밀수 있다는 점이 흥미로웠다.

## 파라미터를 바꿨을 때 어떤 변화가 있었는지

### SCALE 값 변화

SCALE 값을 낮게 설정했을 때는
지형이 완만하고 부드러운 형태로 생성되었다.

반대로 SCALE 값을 높이면
높낮이 변화가 커지고 산악 지형처럼 험준한 형태가 만들어졌다.

즉, SCALE 값이 지형의 거칠기와 변화량에 큰 영향을 준다는 것을 확인할 수 있었다.

### OCTAVES 값 변화

OCTAVES 값을 낮게 설정하면
단순한 형태의 지형이 생성되었다.

반대로 값을 높이면
작은 굴곡과 세부 디테일이 많이 추가되어
더 자연스럽고 복잡한 지형이 만들어졌다.

특히 OCTAVES 값을 높였을 때
훨씬 현실적인 느낌의 월드가 생성되는 점이 인상적이었다.

## 기말 프로젝트에서 프로시저럴 생성을 활용할 수 있을지

기말 프로젝트에서도 프로시저럴 생성을 충분히 활용할 수 있을 것 같다.

특히 랜덤한 스크롤을 기반으로 하는
독특한 시각적 효과를 만들수 있을것 같다.

예를 들어,
게임 진행에 따라 배경 지형이 계속 변하거나,
랜덤한 패턴의 이펙트를 생성하면
반복적인 느낌을 줄이고 더 자연스러운 화면을 만들 수 있을 것 같다.

Perlin Noise를 활용하면
직접 모든 배경을 제작하지 않아도
자연스럽고 다양한 결과를 만들 수 있다는 점이 유용하다고 생각했다.
